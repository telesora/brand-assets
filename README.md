# Telesora brand assets

Official logos and images of Telesora, for partners, press and our own sites.

## Files

| File | Use |
|---|---|
| `logo.svg` | Full logo (mark and name) on light backgrounds |
| `logo-on-dark.svg` | Full logo on dark backgrounds |
| `mark.svg` | The mark alone: a speech bubble with a medical cross |
| `favicon.svg` | Browser tab icon |
| `icon-512.png`, `icon-192.png` | App and profile icons |
| `social-preview-home-en.png` | Social sharing image, 1200 x 630 |

## Colours

| Name | Hex |

| Cream | `#FBF6EE` |
| Terracotta | `#C4532A` |
